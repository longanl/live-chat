# 10 · 统一鉴权守卫

## 问题

无路由守卫；登录态判断用 `id === null`（`undefined === null` 恒 false）导致永久失效；
未登录可进业务页并发出 `/friends/list/undefined` 等无效请求。

## 解决

- `router.beforeEach` 全局守卫 + 白名单 `['/login', '/register']`，`!user?.id` 重定向 `/login`；
- 守卫内兜底建连：`!isConnected → initWebSocket(user.id)`；
- `layout.vue` 判断改为 `!chatStore.currentUser.id`；
- `getFriends` / `refreshUnread` 入口 `if (!currentUser.value.id) return`，杜绝 undefined 请求。

## 落地 ✅

- 文件：`frontend/src/router/index.ts`、`views/layout.vue`、`stores/chat.ts`
- 验证：清空 user 后访问 `/index`、`/contact`、`/p2pchat` 均跳 `/login`，Network 无业务请求
