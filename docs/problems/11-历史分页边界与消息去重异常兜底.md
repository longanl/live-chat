# 11 · 分页边界、去重与异常兜底

## 问题

空会话反复请求 `history`；"已加载到底"判定错误；WS 推送与分页重叠出现重复消息；
接口异常时无提示、产生 unhandled rejection。

## 解决

- 分页大小单一真源：`utils/constants.ts` 的 `HISTORY_PAGE_SIZE = 30`，接口默认值同步；
- "到底" = **返回条数 < limit**（含 0 条）；`beforeId` 只取有 `id` 的首条，避免 WS 缺 id 消息退化；
- `applyMessage` 按 `id` 去重；`loadConversation` / `refreshUnread` / `getFriends` 全部 try/catch + `ElMessage` 提示；
- `loadMore` 加并发锁 + 不可滚动保护，并用 `scrollHeight - prevHeight` 还原滚动位置。

## 落地 ✅

- 文件：`frontend/src/utils/constants.ts`、`api/index.ts`、`stores/chat.ts`、`views/index.vue`、`views/p2pchat.vue`
- 验证：新会话上滚只请求一次；到底后不再发请求；同 `id` 只渲染一次
