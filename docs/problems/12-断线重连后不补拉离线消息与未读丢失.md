# 12 · 断线重连后补拉消息与未读

## 问题

WS 重连成功后不补拉离线期间的消息，未读角标漂移；重连次数用尽后无任何提示，
用户停留在"假在线"状态。

## 解决

- `onclose`（非手动关闭）每 3s 重连一次，上限 5 次；耗尽后 `ElMessage.error('连接已断开，请刷新页面')`；
- 重连成功时 `onConnect` 调用 `chatStore.syncAfterReconnect()`：刷新未读 + 重载当前会话最新一页
  （`loadConversation` 内部按 id 去重）；
- 首次连接与手动登出不触发补偿，稳态请求量不变。

## 落地 ✅

- 文件：`frontend/src/utils/websocket.ts`、`stores/chat.ts`
- 验证：切 offline → 期间收消息 → 恢复网络，聊天区自动补齐、未读数与服务端一致
